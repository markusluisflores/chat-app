## 2026-06-23 — Stale profile links + unread bold fixes

**Decisions:**
- Added `profiles` table to `supabase_realtime` publication (migration 008) — this was the root cause of issue #12. Supabase `postgres_changes` subscriptions silently receive no events for tables not listed in the publication, so the UPDATE listener in `ConversationList` never fired.
- Simplified `ConversationList` unread tracking from `readTimestamps: Map<string, string>` to `readConversations: Set<string>` after user feedback ("do not overengineer this"). Bold logic moved entirely upstream to `ConversationList`; `ConversationItem` receives only a plain `isRead` boolean.
- Removed `profiles` from `load()`'s dependency array in `ConversationList`, replacing direct use of the `profiles` prop with `profilesRef.current`. The `(chat)` layout is dynamic (reads auth cookies), so Next.js re-renders it server-side on every navigation, sending a new `profiles` array reference each time. That reference in the dep array caused `load()` to re-run on every conversation switch, resetting `readConversations` and wiping in-session reads.
- Root cause of refresh-causes-bold (issue #13): `PostgrestBuilder` (from `@supabase/postgrest-js`) is lazy — the HTTP `fetch` only fires when `.then()` is consumed on the builder. Both `supabase.rpc('mark_messages_read', ...)` calls in `useMessages.ts` were missing `.then()`, so `read_at` was never written to the DB, and every page refresh re-read `null` values and showed conversations as bold.

**Changes:**
- `supabase/migrations/008_profiles_realtime.sql` — `alter publication supabase_realtime add table public.profiles`
- `components/conversations/ConversationList.tsx` — full rewrite: `readConversations: Set<string>`, `profilesRef` pattern, `profiles` removed from `load()` deps, `isRead` computed per conversation
- `components/conversations/ConversationItem.tsx` — removed `currentUserId` prop; bold condition simplified to `!isActive && !isRead`
- `hooks/useMessages.ts` — added `.then()` to both `supabase.rpc('mark_messages_read', ...)` calls
- `tests/hooks/useMessages.test.ts` — lazy `PostgrestBuilder`-style mock that only resolves when `.then()` is called; new tests for mount-time RPC and lazy-fetch guarantee
- `tests/components/ConversationItem.test.tsx` — rewritten to match simplified props; 8 tests
